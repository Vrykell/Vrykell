# Vrykell 功能规格与测试清单

> 最后更新: 2026-08-26（新增：AI 代理、权限模式、Skills、MCP、设置页、主题、模型管理 —— 见十六 ~ 二十节）

## 一、终端核心

| ID | 功能 | 预期行为 | 测试方法 |
|---|---|---|---|
| T1 | Shell 启动 | 打开标签后自动连接本地 shell | 启动应用，状态栏绿点，底部输入栏可用 |
| T2 | 命令执行 | 输入命令后回车，输出显示为 Block | 输入 `ls` 回车，页面出现 Block 显示文件列表 |
| T3 | 实时输出 | 命令未结束时，输出在运行中块内可见并持续跟随 | 输入 `for i in 1 2 3; do echo $i; sleep 1; done`，逐行观察输出 |
| T4 | 多标签会话保活 | 切换标签不丢失 shell 状态 | 标签1输入 `export FOO=bar`，切到标签2再切回，输入 `echo $FOO` 输出 `bar` |
| T5 | 退出码显示 | 块 header 显示 ✓(成功) 或 ✗(退出码) | `true` 显示 ✓，`false` 显示 ✗ 1 |
| T6 | TUI 全屏模式 | nano/vim/htop 等程序自动全屏 xterm.js | 输入 `nano`，终端变为全屏 |
| T7 | TUI 退出恢复 | 退出 TUI 程序后恢复 block 列表模式 | 在 nano 中 Ctrl+X 退出 |
| T8 | TUI 键盘直通 | TUI 模式下键盘输入直达终端 | 全屏时按键直接作用于程序 |
| T9 | TUI 提示栏 | 全屏时底部显示 "TUI 模式" 提示 | 视觉检查 |

## 二、Block 命令块

| ID | 功能 | 预期行为 | 测试方法 |
|---|---|---|---|
| B1 | 块 header | 每块显示命令文字、耗时和退出状态 | 执行任意命令，观察块头部 |
| B2 | 运行状态 | 运行中显示状态灯，完成后显示退出码 | 执行 `sleep 3` 和 `false` |
| B3 | 展开/折叠 | 点击 ▾/▸ 按钮切换，有动画 | 点击块的折叠按钮 |
| B4 | hover 工具条 | 鼠标悬停显示 ⭐🔄📋⋯ | 鼠标移到块 header 上 |
| B5 | AI 解释 | 点击 ⭐ 发送输出给 AI | 执行命令后，hover 块，点击 ⭐ |
| B6 | 重新运行 | 点击 🔄 重跑该命令 | hover 块，点击 🔄 |
| B7 | 复制命令 | 点击 📋 复制命令文字 | hover 块，点击 📋，粘贴验证 |
| B8 | 更多菜单 | 点击 ⋯ 打开完整操作菜单 | hover 块，点击 ⋯ |
| B9 | 块分隔线 | 细线延伸到终端两侧边缘，文字保留内边距 | 执行多个命令观察 |
| B10 | 右键菜单 | 右击块弹出上下文菜单 | 右键点击块区域 |
| B11 | 自动滚动 | 贴底时跟随运行中输出；上滚阅读历史后，打开面板或调整窗口宽度仍停留在原来阅读的文字附近 | 执行持续输出的命令，滚动到历史内容后打开面板并调整窗口宽度 |
| B12 | 输出不含乱码 | 不显示 `]133;D;0` 等 OSC 序列 | 执行命令后检查输出 |
| B13 | 输出不含提示符 | 不显示 shell prompt 文字；块模式在行编辑器重绘后标记输出开始并重置 PTY 屏幕起点，避免旧认证文本与绝对光标位置带入新命令 | 执行命令后检查输出、提示符残留及多余空白 |
| B14 | 底部输入栏 | 终端与 AI 输入栏固定在底部，使用一致的卡片边界、模式标题与间距 | 打开终端与 AI 面板观察 |
| B15 | 输出保留与截断提示 | 超过可见高度的输出进入滚动历史，不算截断；仅缓冲区实际丢弃较早的行时统计并提示；宽窗口按实际内容宽度分配终端列数，保留命令自身的换行与对齐 | 检查 100 行输出无截断提示；超出 5000 行滚动历史时核对实际丢弃行数；1550px 窗口输出超过 160 列的单行 |
| B16 | 并发终端初始化 | 相同版本的集成脚本直接复用，更新通过临时文件原子发布；同时打开多个终端时不读取半写入脚本 | 并发启动与更新时持续读取，校验完整脚本内容 |
