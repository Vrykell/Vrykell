# Vrykell 功能规格与测试清单

> 最后更新: 2026-08-26（新增：AI 代理、权限模式、Skills、MCP、设置页、主题、模型管理 —— 见十六 ~ 二十节）

## 一、终端核心

| ID | 功能 | 预期行为 | 测试方法 |
|---|---|---|---|
| T1 | Shell 启动 | 打开标签后自动连接本地 shell | 启动应用，状态栏绿点，底部输入栏可用 |
| T2 | 命令执行 | 输入命令后回车，输出显示为 Block | 输入 `ls` 回车，页面出现 Block 显示文件列表 |
| T3 | 实时输出 | 命令未结束时，输出在运行中块内可见并持续跟随 | 输入 `for i in 1 2 3; do echo $i; sleep 1; done`，逐行观察输出 |
| T4 | 多标签会话保活 | 切换标签不丢失 shell 状态 | 标签1输入 `export FOO=bar`，切到标签2再切回，输入 `echo $FOO` 输出 `bar` |
| T5 | 退出码显示 | 块 header 显示 ✓(成功) 或 ✗(退出码) | `true` 显示 ✓，`false` 显示 ✗ 1 |
| T6 | TUI 全屏模式 | nano/vim/htop 等程序自动全屏 xterm.js | 输入 `nano`，终端变为全屏 |
| T7 | TUI 退出恢复 | 退出 TUI 程序后恢复 block 列表模式 | 在 nano 中 Ctrl+X 退出 |
| T8 | TUI 键盘直通 | TUI 模式下键盘输入直达终端 | 全屏时按键直接作用于程序 |
| T9 | TUI 提示栏 | 全屏时底部显示 "TUI 模式" 提示 | 视觉检查 |
