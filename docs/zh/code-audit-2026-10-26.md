## 继续复查

- 目录同步复用共享的命令行构造器，拒绝全部终端控制字符；远程目录命令保留字面参数语义。
- 活跃终端记录实际解析出的系统默认命令行；即使布局没有指定类型，目录选择器和路径补全也使用该运行时记录。
- 空暂存目标在路径归一化后仍为空，避免变成根目录撤销映射。
- 文件打开降级元数据使用前端约定的字段名；远程模板替换全部文件占位符，远程父目录使用远程路径语义。
- 高亮遍历解码后的文本节点，保留实体并标记全部匹配，不改写属性。
- 快照样式拒绝转义、注释及引号形式的图片来源。
- 搜索、抓取及注册表请求的失败摘要按字符截断，支持多字节响应。
- 文件搜索和技能发现、复制跳过链接目录循环；文件搜索也跳过特殊文件并限制内容读取。
- 技能安装使用唯一暂存目录，替换成功前保留旧安装。替换失败恢复旧目录；若恢复也失败，则在错误报告的恢复路径保留旧副本。
- 已审查的分组方案支持尚未持久化的空标签，不创建空历史；等待已有首次写入，并拒绝等待期间已关闭的标签。允许保存空分组元数据，已有会话的成员关系继续按事务校验。
- 子快捷菜单先于父配置选择器处理 Escape；数字切换侧栏对话后恢复输入焦点，使下一次快捷键仍由同一工作区处理。
- 单个终端标签的拖拽预览保留实际测量宽度，自动宽度只用于分组预览。
- 布局未指定命令行类型时，多行脚本提交也读取实际进程类型。

## 验证与边界

验证在当前桌面工作区执行。链接目录和特殊文件测试仅在支持相应夹具的系统上编译。外部服务及打包辅助程序测试保留既有的显式排除。

严格界面静态审计仍报告 64 项既有问题：29 项所有权启发式未决项、35 项静态规则违规。这些问题尚未解决，不将该检查描述为通过；现有交互契约已记录这些类别。运行时浏览器、类型及架构检查分别记录。

最终验证：类型检查、完整前端单元测试和架构检查通过；后端测试 321 项通过、5 项按既有条件忽略。首次浏览器全量测试为 710 项通过、85 项失败、2 项跳过，随后逐项检查并修复代码或过时夹具；中间串行复测为 78 项通过、16 项失败。剩余修复后的最终确认覆盖失败场景及新增回归，共 90 项通过。这不等于一次完整全量测试全部通过。新增测试不需要生产凭据或外部服务调用。
