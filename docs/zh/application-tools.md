# 外部会话使用应用工具

外部会话通过现有的新建和恢复会话请求接收会话专属的标准输入／输出工具服务器。它适配原生对话已有的工具实现，不另建执行或权限引擎。

首期白名单包含命令执行、终端读取与按键、文件读取／写入／编辑、目录列表、文件搜索及用户提问。策略禁止的工具不会发布。终端默认不绑定，用户在已有输入区状态栏选择目标。每轮固定该目标，切换工作区焦点不能重定向执行。运行期间不能更换目标；更换目标会更新授权身份并清除旧授权，即使清理延迟也不能跨目标复用授权。远程目标不能调用本地文件工具。

问题与审批复用已有对话卡片。同一轮的调用串行执行；拒绝后，该轮除提问以外的工具均停止，回答问题不能解除限制。停止会取消问题和审批等待。策略判定、系统确认及一次性执行租约仍以后端为准。

应用辅助模式在创建窗口和单实例处理之前进入，向临时回环套接字转发有长度限制的协议消息。随机会话令牌只通过辅助进程环境提供，不进入命令参数、保存配置或诊断日志。它不是网页或公网服务，浏览器请求不能通过其分帧认证握手。

每个会话独立持有监听器、令牌、待处理请求及活动轮次代号。初始化和历史重放期间不能执行工具。结果只能答复同一活动连接中未结束的请求。关闭会话释放监听器和辅助连接。投递失败、会话关闭或请求过期均拒绝执行。只有主窗口能够答复工具结果。

首期不提供凭据、任意应用命令转发、外部工具服务器递归调用、调度、安装和子代理创建。外部智能体仍可能拥有独立工具，该适配层不隔离那些进程。现有协议版本及客户端文件／终端能力声明保持不变。

原生测试覆盖传输认证、工具目录校验、非活动轮次、结果关联、取消、过期轮次及消息长度。单测与浏览器测试覆盖参数校验、固定目标、拒绝、提问及对话归属。可选进程测试通过 `APP_TEST_MCP_HELPER_EXE` 使用开发可执行文件，验证输出仅包含协议消息，并且无需创建窗口即可退出。
