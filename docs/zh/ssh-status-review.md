# SSH 状态与服务认证审查

## 范围

以 `dev` 的 `c531f84` 为基线，审查 SSH 状态侧栏、终端状态入口、连接日志、资源采集、
SFTP 恢复操作、临时服务认证及相关测试。分支保留 dev 当前的聊天、诊断、终端 I/O 与文件属性实现。

## 已处理的问题

| 范围 | 问题与处理 |
| --- | --- |
| 认证恢复 | 终端可回退到密码登录，文件／资源连接却继续使用被拒绝的已保存私钥。两个面板现在提供共享认证弹窗，可输入服务器密码或已配置私钥的解密口令，不修改已保存配置。 |
| 凭据隔离 | 临时凭据绑定连接 ID、主机、端口、账户、私钥路径、跳板机与认证方式；提交时地址与账户仍须匹配已保存连接。发送凭据前执行主机密钥校验。 |
| 凭据生命周期 | 认证成功后才缓存。保存／删除配置、主动清除、认证被拒及最后一个存活终端结束时失效。请求版本阻止迟到结果恢复已清除凭据；旧请求失败也不能移除新凭据。缓存与待处理请求均有数量上限。 |
| 秘密处理 | 密码与口令通过明确脱敏的 IPC 字段传送，提交时清空密码输入框，不进入前端状态仓库、连接配置写入或诊断载荷。Rust 拥有的临时缓冲使用 zeroize；凭据对象不实现 Debug 或 Serialize。 |
| 连接日志 | 无 Shell 集成时，旧逻辑可能把普通 Shell 输出保留为连接历史。现在仅保留识别出的客户端提示与生命周期信号，并脱敏、限制每行 1,024 字符及最多 60 条。 |
| 重试行为 | 认证失败停止自动资源重试；手动刷新或共享认证成功后可恢复。普通传输失败仍延迟重试。 |
| 远端执行 | 资源采集使用独立通道发送固定脚本，合并并读完输出，限制响应为 16 KiB，设置网络与会话超时。不向用户交互终端写入探针。远端字符串按文本渲染；现有终端快照继续使用经过转义的 xterm 缓冲渲染。 |
| 测试发现 | 默认单测扫描可能进入下载的参考项目。现已限制为 src 下的项目测试，参考文件不纳入提交。 |

在本次变更范围内，未发现尚未处理的高严重性问题。这是源码与回归审查，不代表对服务器或整个应用作安全保证。

## 使用边界

- 终端继续使用独立 SSH 客户端，不截取终端密码输入；终端回退到密码登录后，服务需明确认证一次。
- 临时凭据只在本次应用运行的后端内存中存活。清除缓存不会撤销已取得凭据引用的网络操作。
  JavaScript／原生传输的瞬时副本不属于 Rust 缓冲清零保证的范围。
- 本次不包含跳板机文件／资源访问及任意多因素交互挑战。服务器禁用 SFTP 子系统时，输入密码也不能开启该能力。
- 浏览器自动测试模拟 SSH 传输；用户服务器的最终验收需要在应用中输入有效凭据，真实密码不写入测试夹具。
