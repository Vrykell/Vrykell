# 2026-10-21 集成修复记录

对应[集成审查](integration-review-2026-10-21.md)的 R1–R9。本次按未完成的集成收敛入口、交互与数据安全问题，不补做尚未规划完成的协议功能。这批修复作为后续工作区布局调整的独立基线提交，原型不属于本批应用代码改动。

## 修复结果

| 审查项 | 修复 | 主要验证 |
|---|---|---|
| R1 对话授权串用 | 批准、判定、撤销携带对话 ID；工具与形态授权按对话隔离，关闭或换执行目标只撤销所属对话 | 后端隔离与撤销测试、`authorizationScope.test.ts`、审批 e2e |
| R2 启动参数 | Windows 解析程序路径后保留原参数数组，由进程构建器编码；去除多余的路径参数与手工脚本包装 | 实际运行原生测试程序及路径、参数含空格的命令脚本 |
| R3 配置丢失 | 去掉页面级延时保存；保存成功后更新列表并关闭表单，保存期间锁定输入；失败保留草稿、显示错误并允许重试；读取损坏配置返回错误，写入经临时文件替换；返回 ACP 空页刷新服务器列表 | `HarnessSettings.test.tsx`、保存后立即离页与重载及返回列表 e2e、后端配置测试 |
| R4 凭据丢失 | 所有目标成功迁移后才删除旧凭据；部分失败保留源值，保留已有端点密钥；保存失败向界面返回失败，不标记已配置 | 后端迁移及重试测试、前端失败写入测试、模型设置 e2e |
| R5 连接残留 | 显式关闭进程树和收发任务，结束等待中的请求；握手探测及失败路径清理；关闭前端状态后忽略迟到事件和迟到打开结果 | 实际空闲子进程关闭测试、等待请求与事件泵测试、迟到打开测试 |
| R6 项目上下文 | 使用聚焦的本地分栏目录，支持 PTY 尚未连接时的上下文；切到其他页面前保留最近本地上下文；排除 SSH 路径，增加主动选目录入口 | 工作区单测、分栏目录 e2e |
| R7 草稿与阅读位置 | ACP 单例工作页内使用共享连接标签，切页和切连接保活；草稿进入共享草稿仓库，分别保存阅读位置；新会话新建内部连接 | 工作区及阅读位置单测、草稿、阅读位置和新会话 e2e |
| R8 流式跟随 | 抽取原对话的跟随逻辑供两类对话共用，向上阅读暂停跟随，可回到最新回复；共用输入容器 | 跟随行为单测、流式跟随和暂停 e2e、原对话与输入布局回归 |
| R9 导航被遮挡 | 打开用量、ACP 或激活工作区页面时退出设置视图；搜索和设置入口落到可见页面 | 工作区单测、搜索导航、用量与编辑器 e2e |

ACP 入口复用编辑器的单例页面模式与共享 `FolderTabs`；连接选择、错误、输入框、确认框和焦点约束复用已有组件。关闭有活动任务或草稿的页面、内部标签需确认。连接 ID 与远端恢复 ID 分离，避免不同进程返回相同远端 ID 时互相覆盖。诊断删除目录、命令与原始错误内容，仅保留元数据。没有修改终端扫描、状态机或编辑器实现。
