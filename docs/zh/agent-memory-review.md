# Agent 架构与本地记忆审查

审查日期：2026-10-26。设计目标是轻量桌面 agent，不增加独立记忆服务、模型下载或新的运行时依赖。

现有流式 SDK 已经负责生成、工具 schema、迭代上限和模型适配。执行目标、取消、队列和审批状态按会话归属，保留这些边界是合理的；再引入一套编排框架会增加重复职责。不存在统一的“现代 agent 框架”认证。本次以状态归属、工具类型、上下文预算、历史重放、持久写入授权和失败恢复作为工程化检查标准。

## 问题与修改

| 问题 | 后果 | 修改 |
| --- | --- | --- |
| 整份事实文件和近期流水追加到系统指令 | 无关、过时事实在不同项目的每次请求中出现 | 按范围保存独立条目，全文检索；最多 6 条、800 个估算 token，仅召回有效且未过期的事实 |
| 更新记忆会覆盖整份文件 | 并发写入丢失修改，矛盾副本累积 | 每个范围使用唯一主题，事务写入，更新必须携带预期版本 |
| 只在检索候选中处理全局覆盖 | 项目新事实未命中关键词时，旧全局事实仍可能返回 | 在排序和分页前排除被有效项目事实覆盖的全局条目；明确归档审查仍保留两者 |
| 记忆写入把存储错误统一报为主题重复 | 只读或故障数据库给出错误的恢复建议 | 仅转换唯一键冲突，保留其他数据库错误 |
| 旧文件没有确认和有效期状态 | 历史假设看起来仍然有效 | 导入为待确认，保留原文件；默认有效期 90 天，工具最多允许 365 天 |
| 下一轮只获得单行工具摘要 | 模型失去执行证据 | 完整返回值与界面预览分开保存，恢复标准调用／结果配对，不执行历史调用 |
| 消息裁剪没有计算指令和工具定义 | 工具运行前就可能超出配置预算 | 预留固定上下文和 schema，计入图片、结果；每步检查，保持调用／结果分组完整 |
| 授权请求可以任意组合工具名和目标命令 | 无关的允许级工具可能获得另一命令的 lease | 授权和审批入口都校验工具与命令的对应关系 |
| 共享界面的特权命令不需要 lease | 直接调用绕过预期的分发约束 | 共用命令注册表与分发检查；一次性 lease 绑定完整参数，界面 lease 同时绑定原生 webview 标识 |
| 内置模型指令中英混排 | 提示词维护和审查不一致 | 模型指令及 schema 说明统一使用英文，回复跟随用户语言，界面文案进入翻译表 |

子代理定义、工具、设置、IPC，以及定时任务和应用轮询均已删除。原配置文件不主动删除。外部 harness 连接仍是原有的独立能力。

## 记忆约定

`~/.vrykell/memory.sqlite` 复用应用已有的嵌入式数据库库及内置全文索引和排序，不增加外部进程、推理接口或嵌入模型。检索属于词法匹配，不是语义推断。短查询返回受限的字面匹配结果。数据库操作不占用界面线程。

条目包含标识、范围、固定主题、正文、状态、来源、更新时间、有效期和版本。本地目录与远程主机／用户／端口／目录隔离；缺少环境信息时使用会话范围。全局事实只用于明确的跨项目偏好；当前项目存在同主题有效事实时，覆盖全局事实。目录范围采用精确匹配，不代表自动发现仓库根目录或继承父目录记忆。

自动召回只查询当前问题，不会加载整份旧资料。禁止记忆工具也会关闭自动召回。结果明确标记为不可信的历史资料，当前用户陈述和观察优先。检索失败不会阻断普通聊天，诊断只记录元数据。

记忆工具提供分页有限读取／检索、新建单条事实、凭标识及版本更新或停用单条事实。`includeInactive` 用于明确查看待确认、过期、停用条目，这些条目不会自动召回。已启用或停用的事实保留原范围，项目覆盖需要另建项目条目；待确认的迁移条目可以在确认时指定范围。写入继续通过既有持久操作审批。固定主题防止精确重复，不能识别任意语义矛盾；情况变化仍需明确更新或停用。有效期是兜底，不表示到期前事实一定正确。

旧文件保留。迁移采用事务和一次性标记，每个文件最多读取 2 MB、导入 1,000 个非空行，每行最多 2,048 个字符。更大或未导入的资料仍保留在原文件，不会自动召回。迁移条目需要确认，并指定合适的主题、范围和有效期后才能启用。

设置页只读取数量统计，没有正文列表、编辑框或批量确认。正文只通过明确的工具操作按需读取。需要关闭记忆访问时，使用工具权限页。

## 保留的边界

- 按用户要求保留轻量 token 和图片成本估算，没有 tokenizer 包或新的计数服务。预算不是模型服务的精确 token 保证。明确关闭上下文管理时仍然不限制历史。
- 完整结果指工具实际返回的完整值，工具自身的范围／读取上限仍然生效。旧的截断预览无法补回原文。重放历史只提供数据，不会再次执行工具。
- 主渲染进程仍然拥有交互终端权限。界面 lease 检查参数、调用界面和单次使用，不证明物理用户手势，也不能隔离同一主 webview 中已完全失陷的代码。既有路径授权和原生执行确认仍然必要。
- 流式循环在渲染进程内按会话运行。保存历史不等于持久化的工具中途检查点，也不提供进程自动恢复；崩溃后不会自动重放任意命令。
- 本地存储和词法排序无法知道未经观察的现实事实已经变化。来源、更新、停用、范围、有效期处理生命周期，不能替代核实。
