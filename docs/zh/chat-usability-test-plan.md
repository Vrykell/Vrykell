# Chat 面板产品可用性测试计划

## 目标与执行方式

从用户完成任务的角度检查 Chat 面板。每项都通过浏览器中的实际按钮、输入、粘贴、菜单或键盘操作完成，观察页面结果；不通过直接改 store 代替用户操作，也不把自动测试通过当成产品体验已通过。

测试使用同一份应用前端与隔离的测试会话。浏览器缺少桌面接口桥接，因此本地测试页模拟数据库、文件接口与模型响应。真实供应商联网、系统文件选择器、SSH 命令执行与桌面数据库集成必须另行验证，不能从本次浏览器结果推断。

每个场景记录：操作步骤、实际结果、通过/失败/受限、截图或可见页面证据、发现的问题与修复后的复测结果。先发现问题，再增加必要的回归测试。

## 测试顺序与通过标准

| ID | 使用场景与操作 | 边界条件 | 通过标准 |
| --- | --- | --- | --- |
| C01 | 打开面板，输入问题，点击发送，阅读完整回复 | 新对话、未绑定终端 | 问答出现一次；回复可读；输入清空；不误操作终端 |
| C02 | 连续发送三轮消息 | 按钮发送与 Enter 混用 | 顺序正确；后续问题可以继续发送；历史没有重复或丢失 |
| C03 | 输入空白、空格、换行后尝试发送 | 无附件、无引用 | 不产生空消息；发送状态符合实际可发送内容 |
| C04 | 输入多行，使用 Shift+Enter、Enter、Esc | 中英文输入、多行草稿 | 换行和发送不混淆；草稿取消行为清楚；输入法确认不误发送 |
| C05 | 查看标题、历史、新建、附件、权限、模型、发送和消息操作提示 | 鼠标停留与键盘焦点；面板边缘 | 提示准确、完整、不遮挡关键操作；聚焦背景有足够留白 |
| C06 | 重发最新回答 | 回复完成、回复失败 | 只替换目标回答；不会新增重复问题；状态及时结束 |
| C07 | 重发第一轮回答，再切换会话并刷新 | 已存在后续两轮消息 | 回答仍在原问题下面；后续问答不串位、不丢失 |
| C08 | 编辑最新问题，取消确认，再确认编辑并修改发送 | 输入框已有未发送草稿 | 取消保留草稿与历史；替换草稿有明确提醒；确认后输入框聚焦 |
| C09 | 编辑第一轮问题 | 后续问题、回答、附件均已存在 | 提示后续消息将被移除；只移除提示范围；原问题与上下文正确恢复 |
| C10 | 重发、编辑、复制、删除菜单的键盘操作 | Esc、Tab、方向键、Enter | 菜单和弹窗可退出；焦点返回合理位置；取消不改变数据 |
| C11 | 复制回答与代码块 | 多段 Markdown、代码、工具结果 | 剪贴板内容对应用户选择，且无漏文本或误复制问题 |
| C12 | 删除一段测试问答，先取消再确认 | 第一段、最后一段、唯一一段 | 取消无变化；确认只删目标；刷新后结果一致 |
| C13 | 粘贴长文本，预览、取消预览、移除、发送 | 纯附件发送、附件加文字 | 附件位于输入上方；名称可读；发送后上下文保存，草稿附件清空 |
| C14 | 添加图片与普通文件 | 同时多个、重复名称、取消选择 | 预览、移除、数量与实际一致；不会因取消选择清空已有附件 |
| C15 | 编辑带附件的消息，再发送 | 图片、长文本、终端引用 | 原附件与引用恢复；不串到其他会话；重新发送后仍可阅读 |
| C16 | 等待较慢回复，继续输入下一条草稿，再停止 | 尚无内容、已有部分内容 | 停止可达；等待结束；下一条草稿保留；停止后可继续发送 |
| C17 | 模拟连接失败，阅读错误，重试 | 失败无内容、失败已有内容 | 错误能理解；有恢复路径；不会无限忙碌或重复添加问题 |
| C18 | 生成长回答，上滚阅读，继续生成，回到最新 | 超过一屏、代码与列表 | 阅读位置不被抢走；最新入口可达；恢复跟随后正确到末尾 |
| C19 | 切换模型，搜索、选中、取消 | 长模型名称、窄面板、对话中途 | 当前选择明确；取消不变；草稿、历史保留；菜单不溢出 |
| C20 | 查看四种对话/审批选项及其说明 | 键盘与窄面板；不同模型的模式覆盖 | 选中项与说明一致；菜单紧凑；取消无变化；安全语义不因 UI 变化改变 |
| C21 | 创建两个对话，在历史中搜索并来回打开 | 两个不同草稿与附件 | 各自消息和草稿独立；历史入口直接可见；没有跨会话覆盖 |
| C22 | 重命名对话，再从历史查找并刷新 | 空标题、长标题、取消编辑 | 标题行为清楚；不挤掉历史/新建；恢复后名称一致 |
| C23 | 关闭并重新打开面板，再刷新页面 | 未发送草稿、已发送消息、附件 | 开关面板不丢内容；刷新保留能力与产品承诺一致 |
| C24 | 选择执行终端，切换工作区，再关闭所选终端 | 仅讨论、断开、另一终端仍在线 | 目标不会偷偷切换；断开提示明确；讨论仍可继续；代码操作状态正确 |
| C25 | 接收并查看工具调用及审批结果 | 运行、待审批、失败、停止 | 工具状态和结果可读：成功不额外标注（安静的即已完成，也不显示退出码），失败看红色错误框，运行中、待审批与已拒绝仍标出；失败默认展开，可从该行再次收起；待处理动作可达；普通回答不套终端块外观 |
| C26 | 拖窄/拖宽面板，调整窗口，放大字体 | 180/320/480px 面板；720px 窗口；150% 字体 | 按钮不出屏；布局不换乱；名称合理省略；弹窗和菜单可操作 |
| C27 | 发送、重发或编辑时切换到另一会话 | 另一会话已有草稿；后台任务未结束 | 显示工作中的会话；操作不会作用到错误会话；返回后内容正确 |
| C28 | 检查保存失败提示与重试保存 | 用户消息、回答、删除保存失败 | 内存内容不丢失；失败有明确提示；重试后刷新结果一致 |

## 本次已发现的问题

1. 重发较早回答后，刷新把新回答排到后续消息之后：浏览器已复现，修复后已再次通过实际重发与刷新确认。
2. 编辑重发没有明确提示会覆盖未发送草稿：已增加提醒，取消保留草稿已通过实际操作确认。
3. 编辑完成后的输入焦点与确认取消后的焦点：继续复测。

## 完成标准

逐项标记结果并保存证据；修复已确认的问题，重新操作相关完整流程；运行必要的单元及 E2E 回归。最终报告区分已验证、已修复和环境受限项，不使用“所有功能正常”概括未测试的功能。
