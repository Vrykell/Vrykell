## 一、终端核心

| ID | 功能 | 预期行为 | 测试方法 |
|---|---|---|---|
| T1 | Shell 启动 | 打开标签后自动连接本地 shell | 启动应用，状态栏绿点，底部输入栏可用 |
| T2 | 命令执行 | 输入命令后回车，输出显示为 Block | 输入 `ls` 回车，页面出现 Block 显示文件列表 |
| T3 | 实时输出 | 命令未结束时，输出在运行中块内可见并持续跟随 | 输入 `for i in 1 2 3; do echo $i; sleep 1; done`，逐行观察输出 |
| T4 | 多标签会话保活 | 切换标签不丢失 shell 状态 | 标签1输入 `export FOO=bar`，切到标签2再切回，输入 `echo $FOO` 输出 `bar` |
| T5 | 退出码显示 | 块 header 显示 ✓(成功) 或 ✗(退出码) | `true` 显示 ✓，`false` 显示 ✗ 1 |
| T6 | TUI 全屏模式 | nano/vim/htop 等程序自动全屏 xterm.js | 输入 `nano`，终端变为全屏 |
| T7 | TUI 退出恢复 | 退出 TUI 程序后恢复 block 列表模式 | 在 nano 中 Ctrl+X 退出 |
| T8 | TUI 键盘直通 | TUI 模式下键盘输入直达终端 | 全屏时按键直接作用于程序 |
| T9 | TUI 提示栏 | 全屏时底部显示 "TUI 模式" 提示 | 视觉检查 |
| T10 | 切回标签重绘 | 终端所在标签或面板被隐藏后切回时，从缓冲区重绘画面：静态全屏 TUI 不再黑屏，隐藏期间丢失的 WebGL 上下文恢复并重绘；重绘只刷新缓冲区，不清空与其它终端共享的字形图集（图集级重置是应用级动作：清空一次并刷新全部活终端）。页面从后台恢复（visibilitychange）走应用级重置并合并为一次 | 运行全屏 TUI，切到另一标签停留后切回，画面仍在；`terminal-visibility.spec.ts` 断言切回时触发重绘 |
| T11 | TUI 多字节编码 | GUI 启动的 shell 自动补上 UTF-8 区域设置（`LC_CTYPE`，`LANG` 为空时一并补），vi 等区域感知的全屏程序不再把中文渲染成 `~X`；环境里任一变量已请求 UTF-8 时保持原样 | 在无 `LANG`/`LC_*` 的环境启动应用，用 `vi` 打开含中文的 UTF-8 文件，中文正常显示；Rust 单测覆盖 locale 决策 |
| T12 | TUI 窗口标题 | 前台程序通过 OSC 0/2 设置的窗口标题（如运行中的动画）在命令运行或全屏期间显示在标签与标题栏，复制出的会话也响应标题更新；命令结束或退出全屏后还原为自动标题；手动重命名过的标签不被覆盖 | 运行一个会设置标题的命令（如全屏工具），观察标题随其更新、退出后还原；`tab-title.spec.ts` 断言显示、还原及复制会话行为 |
| T13 | 真 alt 屏优先于手动全屏 | 手动全屏（运行中块的「进入全屏交互」）期间程序进入 alternate buffer 时，手动全屏立即让出可见面，改由主 xterm 展示实时 TUI：不再黑屏，「重绘终端」重绘的是真正可见的那个终端 | `running-term.spec.ts`「手动全屏中进入真 alt 屏」与 `useTerminalSession.test.tsx` 对应用例 |

## 二十四、文件面板搜索与对话延续

- 目录读取成功后才切换并保存路径。错误路径保留当前视图并显示通知；读取失败时保留面包屑并提供返回默认目录的入口，终端目录操作只使用读取成功的目录。
- 本地和远程文件面板均在顶栏提供搜索浮层，递归按文件名检索。选择文件后进入父目录并选中，选择文件夹后进入目录。两种终端目录操作一起放入更多菜单，面板导航文案改为“切换到当前终端文件目录”。
- 搜索最多返回 200 项，遍历 500 个目录、20,000 个条目及 12 层子目录。本地搜索跳过符号链接；远程搜索使用同一个认证后的 SFTP 通道，支持取消并提示跳过的目录及不完整结果，连接成功后的遍历预算为 20 秒。
- 外观设置提供独立的 AI Chat 面板字号，范围 10–24 px，立即生效并自动保存，支持预览和恢复默认。
- 独立对话在终端关闭和设置页导航后继续保存。旧消息迁移后保留原 pane 和时间戳；旧内联历史始终留在来源终端，不受 AI 面板开关影响。
