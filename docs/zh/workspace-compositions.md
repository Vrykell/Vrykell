# 工作区组合

## 所有权

组合使用与终端、代码和 AI 区域共享的权威 `WorkspaceContainer`，标签持有资源引用布局。归属图和审查见[工作区统一底层](workspace-foundation.md)。终端进程与命令块保留原会话及稳定窗格标识；文档、对比、内置对话和外部连接保留领域状态与关闭保护。聚合标签栏展示组合标签，不再直接展示全部打开资源。每个标签独立保留布局、焦点及临时放大状态。开始页仅在没有内容标签时显示。

每个终端窗格只暴露一个可移动的内容宿主。聚合工作区移动已有宿主，不重新挂载另一份终端。已有终端分屏将原树投影到聚合布局，保留方向、比例与窗格身份，不再嵌套终端布局。切换视图不重启进程、不复制缓冲区。

创建复用终端配置、已保存主机和外部智能体选择器。本地配置与远程主机具有不同选择范围，键盘默认动作也遵守范围。新建文件与打开文件保持独立；从聚合工作区发起的操作仍留在该工作区。

四个工作区的标签栏均将公共资源切换入口放在最左侧。右侧工具栏移除重复的资源切换与拆分按钮；编辑器的在终端打开和对话的选择项目操作仍可通过菜单访问。标签及窗格右键菜单通过“拆分标签页”二级菜单列出当前区域可创建的资源类型。终端、服务器和智能体选项仍打开完整选择器，选择落点后才创建资源。聚合工具栏为当前原生或外部对话提供停靠侧栏按钮；空间不足时保留原主区位置。

## 历史与恢复

启动只恢复已保存工作台引用的终端所有者，包括混合布局中的终端，不再恢复数据库中所有残留的活动记录。组合记录不会创建终端进程。旧的未选中、未编辑、默认标题空白对话只清理标签位置，不删除对话历史；当前选中、已命名、已分组、共享引用及有内容的草稿均保留。仅停靠侧栏的会话不会使智能对话开始标签消失。

现有历史仓库以 `workspace` 元数据记录保存组合。带版本的载荷只包含共享布局、焦点和有界引用，不包含正文、命令、文件内容或凭据。比例、焦点及成员变化更新同一标签标识，恢复沿用该标识。每个标签独立串行写入，切换标签不会把待保存的布局写入其他标签。历史状态原子写入，避免启动恢复误把组合当成终端进程。

数据库边界在插入与载荷变更时维护类型及分屏摘要。兼容事务迁移新增摘要列，只回填一次旧记录。分页筛选读取摘要，不在每次查询时解析所有布局。混合组合匹配每一种成员类型，全部、单窗格及分屏是独立条件。恢复对话元数据按主键读取单条记录，不加载完整目录。

列表中一个组合只显示一条记录，带窗格数量与成员类型；展开可查看成员，默认恢复完整布局。移除组合历史只删除元数据，不删除被引用资源。

历史入口显式传递恢复目标。从聚合工作区进入的历史，包括单资源，恢复后仍留在聚合工作区；混合组合始终使用聚合工作区。统一服务调用原领域恢复动作，将历史标识映射为存活引用，全部成员解析后才提交布局。缺失成员会报告错误，不覆盖当前布局。正在进行的同一成员恢复会合并，后续独立用户动作仍可使用。

外部引用携带准确会话标识与目录，不修改全局最近使用记录。未保存草稿缺失时，不创建空白替代文档。分屏通过共享落点控制器新增同级窗格；移出为新标签和合并标签保留原资源，合并前明确选择落点。放大只改变展示，不丢弃原布局。关闭窗格关闭对应资源；关闭整组标签先检查全部文档及外部会话保护，再关闭任何成员。各区域使用同一分组模型和删除/归档生命周期，原生历史在存储边界适配；全部区域共用几何、分隔线与落点控件。

## 回归清单

编辑器和智能对话工作区使用同一窗格状态工厂创建独立引用布局，与混合组合复用内容宿主画布、落点及分隔线，不跳转聚合工作区。终端工作区通过原生存储格式适配共用泛型树操作和窗格画布。每个内容宿主仅由可见槽位占用，不可见槽位不能覆盖所有权。聚焦的原生资源保留本工作区标签栏；同类组合从原生历史恢复时回到对应原生工作区，聚合入口的恢复保留在聚合区。

- 创建范围、键盘默认动作正确，创建与打开文件保留目标工作区。
- 按成员类型匹配，分屏独立筛选，有界游标分页。
- 整组及成员恢复、缺失引用、重试和准确外部会话引用。
- 调整比例、恢复组合沿用历史标识，不重复写入或复制内容。
- 原终端分屏平铺接入，不重启进程、不丢失草稿。
- 移动窗格保留所有者，关闭窗格和标签保留保护。
- 标签独立布局、合并落点、可还原放大及仅空工作区显示开始页。
- 兼容迁移、摘要维护、异常元数据及内容字段拒绝。
